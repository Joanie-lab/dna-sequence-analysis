# DNA Sequence Analysis with Python

A beginner project that reads DNA sequences from a FASTA file and calculates sequence length, nucleotide counts, GC content and reverse complement.

## Files
- `dna_analysis.ipynb`: the Google Colab notebook containing the code and documentation

## How to run it
Open the notebook in Google Colab and run all cells.

## What I learned
Applying basic Python (functions, loops, dictionaries and error handling) to a biological problem, and testing it on a real sequence from NCBI.
